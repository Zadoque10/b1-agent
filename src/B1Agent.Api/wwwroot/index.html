            ARCHITECTURE | DESIGN PRINCIPLES

            Built to be trusted.

            01

            Nothing is written without you

            The agent can only prepare a quotation. It reaches SAP when a person clicks Confirm, through an endpoint no tool can call.

            02

            The model never writes queries

            Tools take plain values. The client builds the OData and escapes every one of them.

            03

            Code does the maths

            Aging, credit, ATP and reorder rules are tested C#. The model receives finished numbers and never does arithmetic.

            04

            Vendor-neutral core

            One IChatClient abstraction. OpenAI, Azure or a local model is a setting.
