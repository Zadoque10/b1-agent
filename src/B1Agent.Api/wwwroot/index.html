    ARCHITECTURE | DESIGN PRINCIPLES

    Built to be trusted.

    01

    Read-only by design

    No tool creates or changes documents. Writes would need a human confirmation step.

    02

    The model never writes queries

    Tools take plain values. The client builds the OData and escapes every one of them.

    03

    Limits outside the model

    Row caps live in code, not in the prompt, so no instruction can lift them.

    04

    Vendor-neutral core

    One IChatClient abstraction. OpenAI, Azure or a local model is a setting.
